목표:
- Base44 결과물과 최대한 같은 사용자 경험, 화면 흐름, 핵심 기능을 로컬 프로젝트로 재구현한다.
- 단순 계획 작성이 아니라 실제 코드를 작성한다.
- 현재 폴더에 Vite + React + TypeScript 기반 웹/PWA 앱을 구현한다.
- 구현 후 로컬에서 실행 가능한 상태로 만든다.

중요 원칙:
- SnapMind는 저장물을 검색하는 앱이 아니라, 저장물이 Agent가 되는 앱이다.
- 핵심 루프는 Feed -> Form -> Talk -> Feedback -> Return이다.
- 사용자는 입력 시 태그/카테고리를 고르지 않는다.
- low-confidence는 사용자 질문이 아니라 내부 strength/confidence로 처리한다.
- 기본 답변에는 source ID, confidence score, 분석 리포트를 노출하지 않는다.
- Worldview Brain Map은 파일 그래프가 아니라 keyword neuron / synapse edge 기반 3D 맵이다.
- Feedback Mode에서 edge weaken/remove가 다음 대화에 반영되어야 한다.

Base44 생성 과정에서 얻은 구현 교훈:
- R3F 기반 Brain Map에서 `Cannot read properties of undefined (reading 'source')` 오류가 반복됐다.
- 따라서 이번 로컬 구현에서는 3D Worldview Brain Map을 React Three Fiber가 아니라 순수 Three.js imperative renderer로 구현해줘.
- d3-force-3d를 쓰되, GraphNode/GraphEdge 도메인 데이터와 3D ViewModel은 반드시 분리해.
- duplicate edge 방지를 위해 graph edge deduplication을 구현해.
- 기본 데모는 외부 AI 키 없이 localHeuristicAdapter로 동작해야 한다.

구현해야 할 핵심 기능:
1. Home 화면
   - 추상 AgentCore
   - ChatPanel
   - SnapBar
   - FeedPreview
   - 3D Worldview Brain Map 진입 버튼 또는 Agent 우클릭/길게누르기

2. Feed
   - 텍스트 입력
   - 이미지/파일 업로드
   - 태그/카테고리 선택 없음
   - RawItem 저장

3. Form
   - RawItem -> Signal -> JudgmentCard -> GraphNode/GraphEdge -> AgentProfile 처리
   - deterministic GraphNode/GraphEdge ID
   - low-confidence는 내부 strength/confidence로만 처리

4. Talk
   - localHeuristicAdapter가 최신 cards/nodes/edges/feedback/profile을 읽어서 답변 생성
   - 데이터 추가 전/후 같은 질문의 답변이 달라져야 함
   - source ID, confidence score, 분석 리포트 노출 금지

5. Worldview Brain Map
   - 순수 Three.js imperative renderer
   - keyword neuron 3D 노드
   - synapse edge 3D 연결선
   - edge/node 선택 가능
   - BrainMapInspector
   - View Mode / Feedback Mode

6. Feedback
   - edge weaken
   - edge remove
   - FeedbackEvent 저장
   - 다음 대화에 피드백 반영

7. Demo
   - 데모 시드 데이터 추가 기능
   - Base44 결과물처럼 바로 시연 가능한 흐름
   - “너무 홀로그램 쪽으로만 가는 건 별로야” 같은 피드백 후 답변 변화 확인 가능

기술 스택:

- Dexie or IndexedDB wrapper
- Zustand or simple React state, 더 안정적인 쪽 선택
